# Source / Evidence Hierarchy

1. Current production source and runtime evidence
2. Deterministic test of the actual boundary
3. Exact relevant SHA CI
4. Current published data
5. Real-browser/public behavior
6. Builder report
7. Current shared memory
8. Historical artifacts, comments and roadmaps

When evidence conflicts, prefer the stronger/current source and record the discrepancy.
