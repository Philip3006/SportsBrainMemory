# DEC-0030 — PostHog Privacy Model

## DECISION

The PostHog PWA integration uses the public EU browser project token only,
anonymous in-memory identifiers, a centralized `sbAnalytics` abstraction,
strict event/property allowlists, no `identify()`, no Session Replay, and no
financial/private betting properties. Analytics is fail-open and must never
block the product.

## STATUS

This design is implemented and tested on PR #221, but remains
`branch_candidate` until the PR is merged and the PWA is deployed. Controlled
test ingestion must be reported separately from real production traffic.
