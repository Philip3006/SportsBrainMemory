# DEC-0031 — Fail-Closed Authority Boundaries

## DECISION

Provider authority, activation, publication, betting, ledger mutation,
scheduler mutation, deployment, and secret changes are separate governed
actions. Missing, stale, conflicting, or malformed evidence blocks the action.

## CONSEQUENCE

Memory can document a path and its evidence without creating permission to run
that path.
