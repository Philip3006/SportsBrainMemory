# FND-20260814-031 — Main card/model-tip paths fixed, compact-mode recommendation still downgrades to Manual

## Verified improvement

At `fd52d1b858dc08caae355de7ed9fab3a36ed47a9`:
- normal `sigCard()` renders no button when the signal is not actionable;
- model-tip `predCard` bet buttons were converted to informational non-action elements;
- canonical actionable Value path remains available.

## Remaining concrete bypass

`renderSport()` compact mode still computes:

`data-source = _cIsValueActionable ? 'value' : 'manual'`

and renders a clickable `compact-place-btn` for every non-HZ signal, even when `_cIsValueActionable` is false.

Therefore an ACTIVE/incomplete/stale/noncanonical recommendation can still become a Manual bet simply by switching to compact mode. This is the same route-specific downgrade class P0-A is intended to eliminate.

## Required closure

- compact mode must render a bet action only for a fully actionable canonical Value signal;
- non-actionable recommendation rows remain informational with no `_openBetModalFromBtn` action;
- no source=`manual` fallback in compact recommendation rendering;
- add browser/JS regression proving a non-actionable compact-mode recommendation has zero bet-action controls;
- preserve canonical actionable compact Value behavior if supported.
