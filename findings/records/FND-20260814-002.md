# FND-20260814-002 — Retryable authoritative-bankroll failure can become permanent rejection

## Problem / evidence

Consumer validation can return no row when authoritative bankroll is unavailable, and the generic rejection path may ACK/delete the pending intent.

## Failure / impact

Transient infrastructure failure permanently loses valid user intent.

## Required closure

Introduce explicit ACCEPT / REJECT / RETRY semantics; RETRY is never ACKed.
