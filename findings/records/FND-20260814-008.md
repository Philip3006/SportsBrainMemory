# FND-20260814-008 — Windowed Bundesliga2 jobs are modeled as globally periodic

## Problem / evidence

BL2 live/closing jobs are active only in specific weekly windows but current stale logic uses global intervals.

## Failure / impact

Correctly inactive jobs appear stale for most of the week.

## Required closure

Model expected windows and use inactive/not_expected outside them.

## Related invariants

- `MON-002`

## Verification

Current status: **resolved** — TASK-P0B-002.

`bundesliga2_live_push`, `bundesliga2_scan`, `bundesliga2_closing_odds`, `bundesliga2_retrain` all publish `expectation_state=not_expected` when off-window; production-verified `status=ok + not_expected`. `bundesliga2_settle` `error + not_expected` — execution failure remains visible without false stale. `WindowedExpectation` semantics applied. Verified in production via [[evidence/records/EVD-P0B-002-PROD-001]].
