# FND-20260814-004 — Browser submit is real, but exactly-once proof is still false

## Problem / evidence

The new Playwright test genuinely enables confirm and submits. Its contract says exactly one `/pending_bets` POST must be captured, but the implementation asserts `len(captured_bodies) >= 1`.

A duplicate request therefore still passes.

## Failure / impact

One confirmation could produce multiple placement requests without failing the release proof.

## Required closure

Require exactly one request (`== 1`), assert method POST, preserve canonical payload/stake/JS assertions, and do not mask duplicate submits with retries/waits.
